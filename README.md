## Featured projects

### [Xosting.net](https://xosting.net): hosting and domain platform

A web hosting and domain provider, built end to end.

- **[xosting-backend](https://github.com/shamshodbekdev/xosting-backend)**: seven
  microservices (Go API gateway and notifier, Django auth and billing, FastAPI hosting,
  domain and support), with a database per service and events over Redis Streams.
  Integrated with ISPmanager 6, RDAP and five Uzbek payment providers (Click, Payme,
  Paynet, Uzum Bank, CHECKOUT.UZ). Kubernetes manifests with HPA, PDB and NetworkPolicies,
  plus Prometheus metrics and OpenTelemetry tracing.
- **[xosting-v2](https://github.com/shamshodbekdev/xosting-v2)**: the public site in four
  languages (Next.js 16, next-intl).
- **[auth-xosting](https://github.com/shamshodbekdev/auth-xosting)**: sign-in and
  registration ([auth.xosting.net](https://auth.xosting.net)).
- **Customer dashboard** ([my.xosting.net](https://my.xosting.net)) and an **admin panel**
  with role-based access.

`Go` `Django` `FastAPI` `PostgreSQL` `Redis Streams` `Celery` `Docker` `Kubernetes` `Next.js`

### [UniPrism](https://uniprism.site): university admissions platform

An admissions and networking companion for students applying abroad, delivered as a
Telegram Mini App and bot ([@UniPrismBot](https://t.me/UniPrismBot)).

- Layered backend (`api → services → repositories`), atomic Redis locks,
  HMAC-SHA256 Telegram auth, CI with `pytest` and `ruff`.
- LiveKit (WebRTC) calls and Google Gemini features.
- Landing page: [uniprism.site](https://github.com/shamshodbekdev/uniprism.site).

`FastAPI` `React 19` `TypeScript` `PostgreSQL` `Redis` `LiveKit` `Docker`

### [Hosfer](https://hosfer.com): web hosting and cloud infrastructure

Hosting and infrastructure platform with Linux server administration.

`Python` `PHP` `React` `MySQL` `Linux` `Docker`
